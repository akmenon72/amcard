# AmCard

The iPhone web app for AmCard: scan business cards, check what was read, keep a card bank,
and add contacts to iPhone Contacts (synced to iCloud).

This repository holds only the app's screens. No keys or card data live here: cards are stored
in Supabase behind your passphrase, and Claude is called from the `amcard` Supabase function.
Backend code: `akmenon72/chula-track-weekly`, folder `amcard/`.

Published with GitHub Pages from the `main` branch.

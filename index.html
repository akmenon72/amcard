How adding to Contacts works
  1. Turn on Settings → [your name] → iCloud → Contacts on your iPhone, so new contacts are backed up to iCloud.
  2. Select cards (or none for all) and tap Add to iPhone Contacts.
  3. iOS shows the contacts. Tap Add All Contacts (or Create New Contact for one card).
  4. The list marks those cards as added, so next time you can pick Select not yet added.
